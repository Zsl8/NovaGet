NovaGet help

NovaGet is a free download manager for Windows. It splits downloads into several connections, resumes broken ones, runs them in queues on a schedule, and takes downloads and videos from your browser.

Getting started

  1. Install NovaGet; it starts in the notification area (the arrow icon near the clock).
  2. Add the browser extension: step-by-step guide. Its button shows Connected when it can reach NovaGet.
  3. Click a link to a file in your browser, or press Ctrl+N in NovaGet and paste an address. The Download File Info dialog shows the size and where the file will go; click Start Download.

The main window

  • Categories (left): All Downloads, Unfinished and Finished, the file categories (Compressed, Documents, Music, Programs, Video), Grabber projects and Queues. Click one to filter the list; drag downloads onto a category or queue to move them.
  • Download list (right): file name, queue position, size, status, time left, transfer rate, last try and description. More columns (Save To, Referrer, Added, Connections) are in View → Show/Hide columns. Click a header to sort; drag headers to reorder.
  • Toolbar: Add URL, Resume, Stop, Stop All, Delete, Delete Completed, Options, Scheduler, Start Queue, Stop Queue, Grabber, Tell a Friend. View → Toolbar changes the button size, hides labels, reorders buttons (Customize…) and switches the toolbar theme.
  • Status bar: number of downloads, active ones, total speed and the speed limiter (click it to turn the limiter on or off).
  • Right-click a download for Open, Open with, Open folder, Move/Rename, Redownload, Refresh download address, Add to queue, Copy address and Properties.

While a file downloads

  • The progress dialog shows the speed, time left and one bar per connection. Its tabs set a speed limit for this download and what to do when it finishes (hang up, exit NovaGet, shut down the computer).
  • Pause keeps everything received so far; Resume continues from there, even after a crash or a restart, when the server supports resuming.
  • If a link expires, use Refresh download address: NovaGet opens the page the file came from; click the link there again and the download continues.
  • Properties (Alt+Enter) changes the folder, address, login and connection count, and checks a checksum (MD5, SHA-1, SHA-256) against the value the website publishes.
  • When a download completes, the Download complete dialog (or a notification) offers Open and Open folder. Nothing is opened unless you click.

Queues and the scheduler

Downloads → Scheduler manages queues. Each queue has a schedule (every day on chosen days, or once), a start and stop time, how many files download at once, retries per file, and what to do when it finishes (open a file, hang up, exit, shut down, sleep or hibernate). Wake the computer to start the queue creates a Windows task that wakes the PC from sleep. The Synchronization queue checks its files on the server and downloads the ones that changed.

Downloads → Speed limiter caps the total speed (optionally for scheduled queues only). Options → Connection → Download limits pauses everything after a set amount per period.

Videos and streams

On pages with a video player, the extension shows a Download this video panel. NovaGet lists the available qualities (and audio languages for DASH), downloads the pieces and joins them with FFmpeg into one file. Live streams are saved as far as they are available. Protected streams (DRM) are refused with “This stream is protected and cannot be downloaded.”

Site grabber

Tasks → Run site grabber explores a website and downloads the files you choose: all images, all videos or audio, files of chosen types, or a complete copy for offline browsing. Steps: start page (and a login if needed), save folder, how deep and how far to explore, and which files to keep. Results appear as they are found; projects are kept under Grabber projects and can run again to fetch only new or changed files.

Privacy and safety

  • No ads, no telemetry. The only connections NovaGet makes besides your downloads are the weekly update check, which Options → Advanced can turn off.
  • Downloaded files are never run automatically. They carry the Windows “downloaded from the Internet” mark, so SmartScreen and Office's Protected View still look at them, and an antivirus can scan each finished file (Options → Downloads).
  • Certificates are always checked; ignoring certificate errors is a per-download choice with a warning.
  • Passwords and cookies are stored encrypted for your Windows account.

Where NovaGet keeps things

  • Settings and the download list: %APPDATA%\NovaGet
  • Unfinished downloads and logs: %LOCALAPPDATA%\NovaGet
  • Portable mode: put an empty portable.flag file next to NovaGet.exe and everything is kept in its Data folder.

Uninstalling asks whether to remove your download list and settings; by default they are kept.
