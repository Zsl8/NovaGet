Install the NovaGet browser extension

The extension hands downloads, links and videos from your browser to NovaGet. The installer has already registered the connection between the browser and NovaGet; you only need to add the extension.

The extension files are in the NovaGet install folder:
  • Chrome, Edge, Brave, Opera, Vivaldi: extension\chromium
  • Firefox: extension\firefox
The default install folder is %LOCALAPPDATA%\Programs\NovaGet (per-user) or C:\Program Files\NovaGet (all users).

Chrome, Edge, Brave, Opera and Vivaldi

  1. Open the extensions page: Chrome chrome://extensions, Edge edge://extensions, Brave brave://extensions, Opera opera://extensions, Vivaldi vivaldi://extensions.
  2. Turn on Developer mode (a switch at the top right, or bottom left in Edge).
  3. Click Load unpacked and choose the extension\chromium folder.
  4. Pin NovaGet Integration to the toolbar if you want quick access to its switch.

Firefox

  1. If the folder contains a signed .xpi file, drag it onto a Firefox window and confirm.
  2. Otherwise open about:debugging#/runtime/this-firefox, click Load Temporary Add-on… and pick extension\firefox\manifest.json. (Temporary add-ons are removed when Firefox restarts.)

Check that it works

  1. Start NovaGet (it runs in the notification area).
  2. Click the extension's toolbar button: the status should read Connected.
  3. Click a link to a .zip or .exe file: NovaGet shows its Download File Info dialog.

Hold Alt while clicking a link to let the browser download it instead.
