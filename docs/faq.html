Frequently asked questions

Back to NovaGet help.

My browser downloads a file itself instead of giving it to NovaGet.

  • Check that the extension is installed and its button says Connected (setup guide).
  • The file type must be in Options → File Types, and the site or address must not be in its exceptions.
  • The browser must be ticked in Options → General → Capture downloads from these browsers.
  • Holding Alt while clicking leaves the download to the browser; Alt+Ctrl forces NovaGet to take it.
  • Some sites start downloads from scripts; right-click the link and choose Download with NovaGet.

The status says “Resume capability: No”.

The server doesn't accept requests for parts of a file. NovaGet then uses one connection, and a broken download has to start over. Nothing in NovaGet can change that; some mirrors of the same file do support it.

A download stopped with an error about an expired link.

Many sites hand out addresses that work for a short time. Right-click the download, choose Refresh download address, and click the file's link on the page that opens. The download continues with the new address and keeps what it already has.

How do I make downloads faster?

  • Options → Connection → Connection type: pick yours; more connections help on fast lines.
  • Some servers limit connections per visitor; NovaGet lowers the count by itself when a server refuses more.
  • Check that the speed limiter is off (status bar) and that no per-download limit is set in the progress dialog.

Why is a video refused as “protected”?

The site encrypts the stream with DRM (such as Widevine or PlayReady). NovaGet never removes copy protection. Unprotected streams, including ones encrypted with a key the site hands to every viewer (AES-128 HLS), download normally.

The checksum doesn't match. What now?

The file differs from what the website published: the download may be damaged or the file replaced. NovaGet keeps the file and marks the download; download it again (right-click → Redownload) or get it from another source before opening it.

Can I use NovaGet behind a proxy?

Yes: Options → Proxy/Socks. By default NovaGet uses the Windows proxy settings. You can also give an automatic configuration (PAC) script, an HTTP/HTTPS/FTP proxy, or a SOCKS 4/4a/5 proxy, each with a login. Test checks the settings with an address of your choice. If an FTP server doesn't work, try turning Use FTP in PASV mode off.

How do I switch to Arabic, or to the dark theme?

View → Language (applies at the next start), and Options → General → Color theme (applies at once; “Use Windows setting” follows the Windows app mode).

Does NovaGet send anything about me anywhere?

No. Apart from your downloads, the only connection it makes is a weekly check for a newer version, which you can turn off in Options → Advanced.

Where are my settings, and can I move them to another PC?

Settings and the download list are in %APPDATA%\NovaGet. Options → Advanced → Export settings writes a file you can import on another PC (passwords are not included). For a USB stick, use portable mode: an empty portable.flag next to NovaGet.exe keeps everything in its Data folder.

Something went wrong. Is there a log?

Yes: %LOCALAPPDATA%\NovaGet\logs (or Data\logs in portable mode). Logs never contain passwords.

Can I use a different FFmpeg?

Yes. FFmpeg is a separate program in the ffmpeg folder of the install folder (an unmodified LGPL build); replace its files with another Windows build. If it is missing, NovaGet looks for ffmpeg.exe on the PATH, and without one it saves the video and audio tracks as separate files.

How do I uninstall?

Windows Settings → Apps → NovaGet → Uninstall. NovaGet is closed first, and you are asked whether to remove your download list and settings (by default they stay). Everything else NovaGet added — shortcuts, browser registration, start-up entry, scheduled wake tasks — is removed.
